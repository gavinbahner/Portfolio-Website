# Modern React Portfolio

A responsive portfolio site built with React, Vite, and plain CSS. No component library is required.

## Run locally

1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Customize

- Edit the filler profile information in `src/main.jsx`.
- Replace the `placeholderImages` URLs with your own image URLs, or point them to local files in `public/`.
- Update `initialProjects` with your real project titles, categories, descriptions, links, and images.
- Update `initialTimeline` with your actual experience.
- Replace the LinkedIn URL and contact details in the footer.
- Styling lives in `src/styles.css` and uses no CSS framework.

## Project modal

Click any project card to open its editable project template. You can change the title, category, image URL, description, and project link during the session. For permanent content, update `initialProjects` in `src/main.jsx`.

## Project carousel

The arrow controls rotate the 2x2 project grid by two cards, creating a smooth animated transition and revealing the next unseen column.
